# 人生の年輪｜一般公開用Webサイト

## 構成
- `index.html`：トップページ
- `privacy.html`：プライバシーポリシー
- `terms.html`：利用規約
- `guidelines.html`：投稿ガイドライン

外部画像、外部フォント、外部JavaScriptライブラリを使わず、HTML/CSS/JavaScriptだけで動く静的サイトです。

## 公開前に必ず行うこと
1. `privacy.html`、`terms.html` の「連絡窓口」を、実際に管理できるメールアドレス等へ変更する。
2. 「人生の年輪」という名称について、J-PlatPat等で商標の先行登録・類似商標を確認する。
3. 将来、実在人物の体験談・音声・写真を掲載する場合は、Web一般公開について本人から明確な同意を取得する。
4. 他者の画像・音楽・文章・フォント等を追加する場合は、ライセンスと利用条件を確認し、必要なら許諾を得る。
5. 投稿機能を追加する場合は、投稿者の権利、第三者の個人情報、削除依頼、違反投稿への対応を実装してから公開する。

## GitHub Pagesで公開する場合
`index.html` をリポジトリのルートに置き、GitHub Pagesで公開できます。公開後は `https://<ユーザー名>.github.io/<リポジトリ名>/` のようなURLになります。

## この版のデモについて
体験画面の人生経験は架空のサンプルです。入力した「あなたの答え」はデモとしてブラウザのlocalStorageにのみ保存され、サーバーには送信されません。

このテンプレートは一般的な公開準備を目的としたもので、個別の法律相談を代替するものではありません。
